# 冻结120/144版本，再训练全新残差修正网络

这是一套独立副本，比较“更好的基础模型上，额外修正是否还有收益”。不会覆盖113版残差模型、120版原模型、原数据和机器人配置。

## 这次固定什么

| 项目 | 设置 |
|---|---|
| 冻结机械臂基础模型 | `bc_training_arm_ring_r08_recovery/run_20261104_152933_829681/best_model.pt`，最佳第138轮 |
| 基础成绩 | 带噪val120/144；无噪val119/144；带噪test132/156，均是基础模型已有成绩，不是新组合成绩 |
| 导航 | 原8→64→64→4模型及权重不变 |
| 新修正分支 | 26→64→64→7，共6,343个可训练参数 |
| 初始化 | 新分支重新初始化，最后层为0，任何观测下初始输出与120版基础模型一致 |
| 推理动作 | 基础力矩＋新修正，每关节修正±5 N·m，合计仍限幅±30 N·m |
| 门控 | 第一版不加距离门控，所有阶段均可修正 |

绝不加载原118/144残差版的修正权重，也不是将两个已有修正结果直接相加。原基础网络所有参数（含不用的辅助头）和独立导航权重冻结，训练及加载时逐参数核验。

## 数据来源与训练起点是两个不同概念

数据仍为此前的原示范＋102条、233,150帧专家恢复示范。恢复示范是在**113版**偏离后由专家接管采集的；这次冻结的模型则是**120版**。

原manifest的`parent_arm_run`、文件哈希和训练目标归属保持原样，不能为了读取方便把采集来源伪改为120。新增`recovery_residual120_context.py`核验120版与113采集模型的划分、归一化以及数据清单相同，再读取数据。新运行config分别记录冻结父模型和数据生成策略。

新修正目标为同一观测上的：

```text
专家力矩 − 120版基础模型输出
```

120版在全部固定训练输入上的预测重新计算、缓存；不沿用113版的残差标签。未增加采集或使用验证、测试集专家动作补标签。这批数据未必覆盖120版剩余的所有失败状态，效果需实测。

## 启动训练

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\train_arm_residual120.py" --device cuda
```

其余设置沿用上一版残差实验，便于比较基础模型改变后的效果：

- 每轮500,000帧，80%原数据＋20%恢复数据；原数据内部低／其他高度各半。
- 原26维输入及原归一化；只对组合动作的后7维力矩求监督损失。
- Adam学习率1e-4、batch4096；修正幅度正则1e-4。
- 最多300轮、至少50轮、早停耐心15轮；只比较训练后最佳验证平衡力矩MSE。
- 原144目标自然帧用于验证，不混恢复训练数据。新分支之外无梯度更新。
- `baseline_model.pt`保存0修正的120版起点，`best_model.pt`保存训练后最佳组合，`last_model.pt`保存末轮；最佳组合不保证超过基础模型。

输出独立放在 `RoboEnv/bc_training_arm_ring_r08_residual120/run_时间戳`。

仅核验数据：

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\train_arm_residual120.py" --check-data-only
```

训练日志中的`delta baseline`改为与**120版第138轮**离线MSE比较；并非与最初113版比较。若需续训，加`--resume-run-dir "本实验已完成目录" --epochs 500`，恢复last的修正权重、Adam、抽样RNG和早停计数；只能续本实验，不能载入旧113残差运行。

## 训练完成后独立测试

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\batch_test_arm_residual120_parallel.py" --split val --duration 20 --sensor-noise config --workers auto
```

默认选最新完成的正式residual120运行，也可加`--arm-run-dir "具体运行目录"`固定模型。沿用144个验证目标、种子、20s和真实末端1cm标准；全程学习模型控制，无专家接管、无强制停车，不改config。

单点仿真入口为`test_arm_residual120.py`，支持同样的`--target X Y Z --duration 20 --sensor-noise config --seed ...`参数。保存的轨迹同时包含基础力矩和新修正量，可检查叠加效果。

先用val与原120/144基础模型、113基础＋残差的118/144比较，再决定是否保留新组合。已报告的132/156作为120版固定历史测试结果保留，不通过反复针对测试点修改来宣称最终泛化改善。
