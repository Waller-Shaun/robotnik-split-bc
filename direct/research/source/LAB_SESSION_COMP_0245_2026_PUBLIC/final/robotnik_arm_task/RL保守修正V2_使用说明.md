# RL保守修正V2

这是一次独立的新试验。冻结120版基线和原导航模型，重新零初始化修正actor及两个critic；不加载失败V1的RL权重。两个机器人配置、原数据划分和旧实验均保留。

## 为什么改

V1共训练20,000个交互步、38回合。前6回合尚未执行学到的修正，有5次达到训练保持要求；后续31个进入机械臂训练阶段的回合均未达到该要求，另1回合导航未完成。目标不同且包含探索，因此不能把这些数字当作正式成功率，但它们是退化警讯。

同点测试`[1,-1.732051,1]`、种子`1956328971`，V1最终误差约14.2 cm；修正RMS约1.89 Nm，约72%的修正分量接近±2 Nm上限。V1的`gamma=.99`按10ms计，3秒后奖励权重仅约4.9%。这些证据促使本版采用更保守的控制范围、时间尺度与选模机制。

## 改动

| 设置 | V1 | V2 |
|---|---|---|
| 最大修正 | ±2 Nm | **±0.3 Nm**，命令行最大允许0.5 Nm |
| 介入区间 | 导航完成后整个机械臂阶段 | 导航完成且**观测末端误差<5 cm** |
| 平滑门控 | 无 | ≤2 cm全幅，2～5 cm连续衰减，≥5 cm严格零修正 |
| 基础动作 | 冻结MLP | 同一冻结MLP；导航轮速仍由原模型产生 |
| 折扣 | 每10ms的gamma=.99 | `exp(-实际物理秒数/10)`，10ms时约.9990005 |
| actor学习率 | 1e-4 | **2e-5** |
| actor零修正正则 | .001 | **.05** |
| actor启动 | critic尚早期时就更新 | 前3,000个交互步actor保持零，只让critic先学习 |
| 探索 | 约0.1 Nm标准差 | 门控前约**0.015 Nm**标准差；测试完全关闭 |
| 模型选择 | 预算最后模型 | 定期验证，并允许选择初始零修正模型 |

actor结构仍为`26 → 64 → 64 → 7 → tanh`。每个critic为`33 → 128 → 128 → 1`。本次改变训练和控制策略，不扩大网络。

门控使用原26维观测中的`23:26`位置误差，**不读取真实末端位置**。基础反馈仍以1kHz更新，actor提案以100Hz更新；门控每1ms重算，离开近区立即停止附加修正。它只限制额外残差，不强制底盘停车，也不施加专家动作。

物理真值只用于训练奖励和评估。训练连续距离惩罚、保持奖励和修正惩罚按真实dt积分，势能差使用相同物理时间折扣；终端势能设零。6秒机械臂修正阶段超时仍bootstrap，真实成功或超过25cm的精细阶段偏离则作为终止。

## 训练与验证

仍在原698个训练目标中抽样，低高度`z<0.5m`和其他高度各占回合抽样概率50%。冻结模型先实际执行导航和接近，最长等待20秒；未进入观测近区的目标记录`no_eligible_near_zone`，不伪造修正经验，也不瞬移。

验证采用从144个val目标中固定随机抽取的**8点小组**：低高度4点、其他高度4点，原始索引为`[29,64,72,107,108,124,130,139]`，使用清单自带种子。初始先测零修正，此后约每5,000个RL步在回合结束处验证。验证无探索，默认配置传感器噪声，20秒内真实距离<1cm即成功，不要求保持。

验证回合不加入经验回放，验证目标不参与梯度更新，测试集不参与训练或选优。每次选模首先要求保留这8点中所有初始基线成功案例，然后优先比较成功数；成功数相同时要求平均最终误差至少降低1mm。

连续3次检查没有产生新的合格最佳模型，并且已训练至少10,000步，触发早停。`--steps 20000`是交互预算上限，并非一定执行到底。若达到500回合上限也会结束并报告原因。

`best_model.pt`现在是真正按这组小验证点选择的模型。**如果始终没有合格改善，它就是初始零修正策略，输出`best RL step=0`。这不能写成“RL取得提升”。** `last_model.pt`单独保留最后训练策略。8点结果只用于便宜地监控与选优，不能保证完整144点都不退化，也不能作为正式成功率。

## 程序验收与局限

已检查门控边界、零修正与基础输出一致、100Hz动作保持、每ms离区归零、物理时间折扣、actor预热期间不更新、CUDA更新，以及选模拒绝丢失基线成功案例的逻辑。

做过8个交互步的smoke：包含仿真、经验回放、6次critic更新/3次actor更新、初始和后续极短验证及早停回退。该smoke使用20ms验证时长，只检验程序，不用于评价效果，不参与自动正式模型选择。

本版多项设置一起改变，属于工程纠偏试验，不能用一次结果单独归因于奖励、门控或学习率。它也无法处理原基线从未进入5cm近区的失败；完整效果仍需正式训练和独立评估验证。
