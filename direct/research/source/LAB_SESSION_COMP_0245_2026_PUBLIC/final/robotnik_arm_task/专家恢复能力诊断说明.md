# 第一步：训练目标附近的专家恢复能力诊断

本程序只诊断，不训练、不把轨迹合并进训练集，也不报告纯模型成功率。专家参与的结果不能当作当前模型的成功率。

## 比较什么

固定当前带噪基线 `bc_training_arm_ring_r08_aux_b2_control/run_20261104_025706_206181/best_model.pt`，导航始终由其绑定的学习策略控制。机械臂先由同一MLP控制。

当机械臂进入目标附近却不再明显改善时，保存同一物理状态、Python侧状态缓存、相位及噪声随机数状态，做两条成对分支：

1. 继续使用模型机械臂。
2. 换成现有专家机械臂控制器。

两条分支恢复相同的起点与随机数状态，各运行最多10s。由于动作不同，之后轨迹自然分叉；导航策略保持相同，但观测不同后输出轮速也可能不同，因此不是冻结底盘或回放同一轮速。

专家接管时将 `q_des` 初始化为当前带噪实测关节角，之后正常积分更新；不借用其他轨迹的参考角度，不读取真实状态纠正动作。采用原 `ArmControllerParams(reach_limit=0.85)` 及原限幅；不强制停车或直接设置关节位置。这个参考重置是本诊断明确的接管策略，并非恢复了未知的历史专家内部状态。

## 默认取样与触发

- 只从冻结清单的train698目标取20个点，交错覆盖z=0.2m、z=0.35m和补采连续低高度；不使用验证集失败坐标作为训练来源。
- 选点不依赖模型成败，默认种子为30042＋原训练索引；不是根据验证成功率挑出来的样本。
- 接管前模型最多运行20s；如果在触发前真实末端已经进入1cm，记录为 `model_reached_before_trigger`，不强行接管。
- 自动触发要求导航规则已done、仿真时间至少8s、最近2s有完整观测。
- 用带噪估计距离的前后0.5s中位数比较：最近距离在1～5cm，2s内改善不足2mm，即近距离停滞。每50ms检查一次。
- 未满足条件的目标记录 `no_eligible_near_stall`，不会任意切换专家。
- `--switch-at` 可改为固定时间接管诊断，但仍要求导航done；默认不使用。

触发只使用观测误差。真实PyBullet末端位置只用于评分，不输入模型、专家或触发器。

## 怎么看结果

每条分支分别记录“任意时刻真实距离<1cm”和“连续保持1s”。这个保持要求仅用于评估恢复稳定性，不追溯改变原正式模型测试的任意时刻到达标准。

| category | 含义 |
|---|---|
| `expert_only_recovered_and_held` | 从同一起点只有专家进入1cm并连续保持1s，值得继续研究恢复示范 |
| `both_recovered_and_held` | 两者都能恢复，不能将结果只归功于专家接管 |
| `model_only_recovered_and_held` | 模型恢复，专家在当前接管策略下未保持成功 |
| `neither_held` | 两者都没保持，需结合各自是否曾到达、停车位置、可达性等分析 |
| `model_reached_before_trigger` | 模型在触发前已经到达；未进行接管比较 |
| `no_eligible_near_stall` | 没出现符合默认阈值的近距离停滞；未接管 |

每个case有 `summary.json`、`model_prefix.npz`、发生接管时的 `model_continuation.npz` 和 `expert_continuation.npz`。动作来源逐步标记；专家参考仅用于诊断记录。NaN参考列表示该步由模型控制，不要把诊断文件直接当作训练数据加载。

总汇总只统计诊断类别，`pure_model_success_rate=null`、`training_data_generated=false`。报告会注明train归属、种子、模型来源、配置快照和哈希。失败进程另记，不从诊断计划中隐去。

## 单点看仿真

从 `--plan-only` 输出中选一个训练目标，填入 `--target X Y Z`：

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\diagnose_arm_recovery.py" --target X Y Z --sensor-noise config
```

不加headless会先播放模型接近，再依次播放同一起点的模型续跑和专家续跑，最后绘制成对真实误差曲线。状态恢复会使画面回到接管时刻，这是成对比较的预期行为。

如果专家能恢复，下一步才考虑小量采集与混合训练；若专家也不能恢复，需要先分析接管初始化、停车误差、可达性、接触或限位。本诊断不自动补采、不自动微调。
