# 数据集结构与扩展计划

我们目前的数据集是**专家控制器的完整运行轨迹**，每条轨迹保存为一个 `.npz` 文件，每个时间步包含以下数据。

## 输入 23维

| 数据 | 维度 |
|---|---:|
| 底盘位置 `[x,y,z]` | 3 |
| 底盘朝向的 `sin(yaw)、cos(yaw)` | 2 |
| 机械臂关节角 | 7 |
| 机械臂关节角速度 | 7 |
| 末端目标位置 `[x,y,z]` | 3 |
| 导航阶段标志：1为导航中，0为导航结束 | 1 |
| **合计** | **23** |

## 输出 11维

| 数据 | 维度 |
|---|---:|
| 四个车轮的目标角速度 | 4 |
| 七个机械臂关节的控制力矩 | 7 |
| **合计** | **11** |

位置单位为米，角度为弧度，角速度为rad/s，力矩为N·m。

## 文件结构与其他记录

文件中的核心字段是：

```text
observations: (N, 23)   当前状态与目标
actions:      (N, 11)   对应的专家动作
timestamps:  (N,)      时间戳
target:      (3,)      本条轨迹的目标位置
```

N表示本条轨迹的时间步数量。

另外已保存末端位置、末端误差、底盘四元数、专家期望关节角和关节速度、实际执行动作及成功信息。

**如果各自的模型还需要其他数据，请在下一次批量采集前提出，一起加入记录。** 辅助字段可以统一保存，各模型自行选择输入，不必都使用相同维度。

## 当前目标范围与划分

目前共有468个目标，范围是：

```text
x：−0.6～0.6m
y： 0.9～1.4m
z： 0.3～0.8m
步长：0.1m
```

初始机器人姿态基本固定，目标主要集中在一侧。现有数据按完整目标轨迹划分为：

| 集合 | 轨迹数量 |
|---|---:|
| 训练集 | 327 |
| 验证集 | 70 |
| 测试集 | 71 |
| **合计** | **468** |

## 后续扩展计划

计划扩大为**围绕小车的环状三维采样**：在专家能够完成的范围内，改变目标相对小车的**方位角、水平距离和高度**，覆盖四面八方及不同远近，而不是只增加当前一侧的目标。

具体范围先通过专家测试确定，再统一采集和划分。
