## 方法区别

我们的主线是底盘网络预测4轮速、机械臂学习策略直接给出7力矩（部分方案再加学习残差），没有新增固定机械臂PD。组员默认结构是31维特征→TCN→7×3运动映射矩阵与7维学习重力补偿→参考速度与积分参考角→固定100/30 PD→力矩。底盘使用冻结导航网络。
