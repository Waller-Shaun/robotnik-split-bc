# 冻结基础模型＋额外力矩修正网络

这是独立新实验，不覆盖原113/144基线、恢复整网微调版、数据或机器人配置。新文件用 `[Residual change]` 等备注标识。

## 模型及动作

```text
同一时刻标准化26维观测
  ├─ 冻结原MLP：26→256→256→128→11 → 后7维基础机械臂力矩
  └─ 新MLP：26→64→64→7 → 每关节±5 N·m的修正
                          ↓
                 两者相加，再按原±30 N·m限幅
```

冻结的基础策略为 `bc_training_arm_ring_r08_aux_b2_control/run_20261104_025706_206181`（带噪验证113/144），不是已完成恢复微调的120/144模型。导航仍冻结绑定 `bc_training_nav_ring_r08/run_20261103_022339_570160`。基础策略全部参数（包含保留但不用的辅助头）和导航权重不更新。

新分支6,343个可训练参数，最后一层权重、偏置为0，初始化时任意输入的修正都为0，组合策略输出与原基线完全一致。模型状态内嵌冻结基础权重，训练与推理逐项核验与原始检查点一致。

修正输出为 `limit_nm*tanh(residual_MLP(x))`，单位N·m。代码先除以原机械臂力矩标准差，转换到标准化动作空间相加，再由测试代码按原标准差和均值反标准化。没有额外加一份动作均值，没有把标准化数值误当物理力矩。

第一版**没有距离门控**，所有阶段都可输出修正；原始示范约束其保留正常动作。也没有直接加专家PD、重力补偿或强制停车。基线权重冻结不代表组合策略永不退步，或具有闭环稳定性保证。

## 训练

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\train_arm_residual.py" --device cuda
```

固定复用现有102条、233,150帧恢复示范清单，无需重采：
`RoboEnv/expert_recovery_data/collection_20261104_112547_770894/episodes/recovery_manifest.json`。

| 项目 | 默认 |
|---|---|
| 输入 | 与原策略相同的26维观测和归一化，无新传感器、无真实位置输入 |
| 标签／损失 | 组合力矩匹配专家；等价于拟合同一输入上的专家力矩减基础力矩 |
| 抽样 | 每轮500,000帧；80%原数据、20%恢复数据；原数据内部低/其他高度各半 |
| 数据划分 | 原698训练/144验证/156测试清单不变；恢复示范仅来自训练目标 |
| 学习率 | Adam 1e-4，只有新分支从头训练；不同于整网微调的1e-5 |
| batch | 4096，GPU常驻单帧数据 |
| 修正幅度 | 默认每关节±5 N·m，`--residual-limit-nm`可设；不放宽总力矩±30限制 |
| 修正正则 | 标准化修正幅度平方均值，权重1e-4；`--residual-penalty 0`可关 |
| 轮数 | 累计最多300，至少50，早停耐心15；不保证一定跑到300 |
| 选模 | 原144目标自然帧的低/其他两组平均力矩MSE，只比较训练后轮次 |

`baseline_model.pt`保存0修正起点，`best_model.pt`保存训练后验证MSE最佳组合，`last_model.pt`保存最后一轮。训练会报告与原基线MSE的差距，训练后最佳不代表一定胜过原基线。新方案与整网微调的学习率、参数化和正则不同，不能将其对照解释成单独冻结一个因素的严格消融。

训练前只计算一次冻结基线在固定输入上的输出并缓存，训练梯度仍完全通过修正分支；这与反复运行冻结网络的目标相同，降低重复计算。每轮检查源文件哈希以及冻结基础权重逐参数不变。没有调用PyBullet仿真，不自动测试。

可先只核验数据：

```powershell
pixi run -e ml python "F:\UCL\COMP0245 Labs\LAB_SESSION_COMP_0245_2026_PUBLIC\final\robotnik_arm_task\train_arm_residual.py" --check-data-only
```

日志：

- `train/val/low/other/balanced`：组合力矩的标准化MSE；验证指标不包含幅度正则。
- `recovery TRAIN`：已有恢复训练片段上的误差，不是独立成功率。
- `correction RMS ... Nm`：验证帧上的物理修正均方根。
- `near bound ...%`：接近修正幅度上限（≥95%上限）的关节坐标比例。
- `stale`：连续未刷新训练后最佳的轮数；达到最低轮数后，计数到15早停。
- `delta baseline`：当前平衡验证MSE减原基线，正数仍高于基线。

还输出 `correction_bound_diagnostic.json`，统计恢复标签所需修正中超过±5 N·m的坐标比例；用于判断限幅是否可能过紧，不自动修改限幅。

输出独立目录：`RoboEnv/bc_training_arm_ring_r08_residual/run_时间戳`。

如需续训，在原命令添加 `--resume-run-dir "已完成的残差运行目录" --epochs 500`。epochs是累计上限；恢复last权重、Adam、抽样RNG、历史最佳和计数，原目录不覆盖。恢复数据、批次大小、学习率、修正限幅及正则需与来源一致。
