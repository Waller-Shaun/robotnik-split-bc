# B4：将辅助标签换成专家当步期望关节角速度

这是另一个角度的辅助监督。原26维输入、实际7维机械臂力矩控制不变，辅助目标从B3的累计参考偏差 `q_des_arm[t] - q[t]` 换为 `qd_des_arm[t]`。

`qd_des_arm` 是专家根据当前姿态、末端误差、雅可比和限位等计算的**期望关节角速度**，不是输入里已有的实测关节角速度。直接读取同帧NPZ字段，单位rad/s；不做差分，不使用下一帧，不减实测角速度。专家计算这一速度时不需要上一步保存的参考角度，但当前观测仍可能缺少部分姿态信息，因此不声称标签完全可由26维输入唯一确定。

## 与B3保持一致

| 项目 | B4设置 |
|---|---|
| 父模型 | 新带噪基线 `bc_training_arm_ring_r08_aux_b2_control/run_20261104_025706_206181/best_model.pt`，最佳185轮，113/144 |

| 实际控制 | 冻结导航模型产生4轮速度，主MLP后7维产生力矩；辅助头不执行任何动作 |
| 梯度门控 | 同B3：共享梯度 `g_main + 0.01 × max(0, cosine) × g_aux`；主动作头仅主梯度；辅助头自身按0.01学习 |
| 训练 | CUDA，lr1e-5，batch4096，每轮最多50万帧，低高度z≤0.35m和其余高度期望各50% |
| 验证 | 原144点全部1,481,313帧；train698点7,306,407帧；不读取test拟合统计 |
| 最大轮数／早停 | 300／20，仅按平衡验证力矩MSE选模 |
| 优化器 | Adam重新初始化，轮次从1计数 |

只对新辅助标签重新计算训练集均值/标准差，验证沿用它们。输入与力矩归一化文件、原清单逐字节继承；没有改原数据、配置或旧脚本。

## 日志与解释

- `balanced` 仍为平衡力矩验证MSE，是最佳权重与早停依据。
- `val aux` 为标准化期望角速度预测误差；与B3参考角偏差的辅助MSE单位、统计分布不同，不能直接比较大小。
- `history.csv` 的 `aux_rmse_rad_s` 是期望角速度预测的物理单位RMSE，单位rad/s，不是末端位置误差。
- `gradient_diagnostics.csv` 沿用B3：cos、冲突比例、辅助激活比例、有效权重及梯度范数。共享辅助梯度开始为0是正常的，辅助头自身仍会学习。
- `total_loss` 为名义固定权重损失；门控模式实际更新由分开的梯度构造。

本次只更换标签及它的统计量，方便和B3比较。新标签可能更贴合当前状态，但不保证帮助力矩或闭环。若没有明确收益，保留负结果，避免无限叠加辅助任务。
